# Solo Bare Ground

Guardrails and kits for building real software with AI coding agents.

**→ [solobareground site](https://qrqr2100.github.io/)**

Eight released kits — five guardrails that catch what an agent gets wrong before it ships, and three kits that make the agent more capable in the first place. Everything here is dogfood: these are the checks I run on my own agents, on real work, every night.

## Guardrails

| | What it does | |
|---|---|---|
| **[Ship Pilot](https://tkwk5.gumroad.com/l/ship-pilot-kit)** | Deterministic gates wired into your repo — blocks the push when something is off | $14 |
| **[Agent Supervisor](https://github.com/qrqr2100/agent-supervisor)** | Supervise autonomous agents: restraint, scope-lint, budget guard, approval inbox, escalation | Free · MIT |
| **[PR Review Craft Kit](https://github.com/qrqr2100/pr-review-craft-kit)** | Review agent-written code the way a senior would — five axes, severity-rated | Free · MIT |
| **[Windows Encoding Preflight Lint](https://github.com/qrqr2100/windows-encoding-preflight-lint)** | Finds and auto-fixes the encoding traps that break AI-written scripts on Korean/Japanese Windows | Free · MIT |
| **[Ship Gate Kit](https://github.com/qrqr2100/ship-gate-kit)** | A pre-ship checklist your agent can't skip | Free · MIT |
